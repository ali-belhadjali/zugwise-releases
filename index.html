Qui a fait Zugwise ?
Moi, Ali Belhadjali, joueur d'échecs. Zugwise est un logiciel libre (licence GPL-3.0). Cette version 2.3.0 est une version de test : ton avis décide de la suite. Le code source de cette version est disponible sur simple demande par e-mail.
Pourquoi Windows affiche-t-il un avertissement ?
Pour que Windows reconnaisse un programme, son éditeur doit acheter un certificat de signature, ce que Zugwise n'a pas encore fait. Windows prévient alors pour tout programme qu'il ne connaît pas. Ce n'est pas un virus détecté. Sur Mac, c'est la même raison.
Que fait l'app de mes données ?
Tes parties sont analysées sur ton ordinateur. Zugwise les récupère sur Chess.com ou Lichess à partir de ton pseudo. Quand tu poses une question au coach IA, la position concernée passe par le serveur de Zugwise jusqu'à l'IA Claude d'Anthropic, qui rédige la réponse. Le compte Zugwise, facultatif, ne demande qu'une adresse e-mail.
D'où vient le fichier ?
De la page des versions de Zugwise sur GitHub, le service où sont publiés la plupart des logiciels libres : github.com/ali-belhadjali/zugwise-releases.
Et si je veux l'enlever ?
Zugwise se désinstalle comme n'importe quelle app : Paramètres → Applications sur Windows, ou glisser Zugwise dans la corbeille sur Mac. L'installation ne demande pas de mot de passe administrateur.

Installer Zugwise

Téléchargement lancé. Voici ce que ton ordinateur va afficher ensuite.

  1. Ouvre Zugwise-Windows-setup.exe depuis tes téléchargements.
  2. Windows affiche « Windows a protégé votre ordinateur ». Clique sur Informations complémentaires.
  3. Vérifie que l'application s'appelle bien Zugwise-Windows-setup.exe, puis clique sur Exécuter quand même. Si un autre nom s'affiche, clique sur Ne pas exécuter et écris-moi à alibelhadjali0@gmail.com.
  4. L'installation se fait toute seule, sans mot de passe administrateur. Zugwise s'ouvre ensuite depuis le menu Démarrer.
  5. Choisis ton coach et entre ton pseudo Chess.com ou Lichess : tes dernières parties arrivent toutes seules.

Pourquoi cette étape ?

Apple demande aux développeurs un abonnement payant pour que macOS reconnaisse leurs apps. Zugwise ne l'a pas encore : macOS te demande donc de confirmer toi-même que tu veux l'ouvrir.
