# Zugwise — téléchargements

Zugwise est un coach d'échecs pour ordinateur : il analyse tes parties Chess.com ou Lichess, t'explique tes erreurs et te propose quoi travailler.

Les fichiers d'installation sont dans **[Releases](https://github.com/ali-belhadjali/zugwise-releases/releases/latest)** : `Zugwise-Windows-setup.exe` pour Windows, `Zugwise.dmg` pour Mac.
